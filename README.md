# SBE YouGile

Центральный сервис авторизации YouGile для плагинов системы SBE. Получает API-ключ
по логину/паролю/ID компании и публикует полный API-клиент YouGile через мост `window.SBE`.
Пароль и ключ хранятся в защищённом хранилище Obsidian (secretStorage).

## Возможности

- Единая авторизация YouGile для всех SBE-плагинов.
- Полный API-клиент (проекты, доски, колонки, пользователи, задачи, чаты, загрузка файлов).
- Сервис публикуется в мост `window.SBE` как `sbe-yougile`: `getStatus`, `authenticate`, `client`.
- UI на русском языке.

## Настройка

Откройте **Настройки → Плагины сообщества → SBE YouGile**:

1. Логин и пароль пользователя YouGile.
2. ID компании (UUID рабочего пространства YouGile).
3. Кнопка «Получить ключ» — авторизация и сохранение API-ключа защищённо.
4. Поле «Состояние» — статус сервиса («Авторизован» / «API-ключ не получен»).

## Для разработчиков

Сервис получают через `getService('sbe-yougile')` (sbe-core). Сигнатуры — в
`sbe-core/src/types.ts` (`SbeYougileApi`). Перед вызовами `client.*` проверяйте
`getStatus().authenticated`.
